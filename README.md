# 入画 · 日出印象

An interactive 3D flight through Claude Monet’s Impression, Sunrise, paced by music.

以莫奈 1872 年的《日出·印象》为灵感，用 TypeScript 和 Three.js 重构勒阿弗尔港。封面和天空使用生成的油画纹理，水面、船、港口、雾与镜头在 WebGL 2 场景中实时渲染。

[打开互动网页](https://0xzzwest.github.io/monet-harbor/)

## 运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run dev
```

运行 `npm run build` 生成静态站点，`npm run preview` 预览构建结果。

点击「飞入画中」开始播放。用 WASD 或方向键平移，空格和 C 升降，拖动画面环顾。触屏有飞行方向键。默认随乐漫游，手动操作后切换到自由飞行。时间轴可定位到任意位置，章节按钮会跳到对应重拍。

## 节拍分析

用 FFmpeg 将原附件解码到 22,050 Hz 的单声道 PCM，以 2,048 样本 Hann 窗和 110 样本步长计算分频带谱通量。多窗口的自相关和周期谱得到约 225.59 次/分钟的八分音符周期，以及约 112.79 BPM 的四分音符脉冲。用开头的入音和第 9、41、49 小节的配器变化定位 4/4 小节相位。重拍定义为每小节第 1 拍。

从 0.432 秒起按拍网格推算，尾段标到仍有乐音的小节。共 87 个重拍，最后一个为 183.420 秒，容器时长 189.893 秒。时间戳四舍五入到三位小数，是对音乐拍点的估计。完整表在 public 目录，音乐为用户提供的原始 M4A。

自动切镜及光色切换使用以下时间，初始画面从 0 秒待机。

| 章节 | 秒 | 小节 |
| --- | ---: | ---: |
| 穿过晨雾 | 17.454 | 9 |
| 舟影 | 51.498 | 25 |
| 雾中桅杆 | 85.543 | 41 |
| 日光破水 | 102.565 | 49 |
| 港湾之上 | 136.609 | 65 |
| 余晖 | 166.398 | 79 |

每帧以 `HTMLAudioElement.currentTime` 为时钟。首次播放时，3D 画面在资源就绪后的下一个重拍进入。每个重拍触发水面反光，随后自然衰减。随乐模式在章节重拍同时切换镜头和色调，自由飞行时保留飞行者的视角。暂停与跳转时，画面从当前播放时间恢复。
